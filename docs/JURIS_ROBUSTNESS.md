# Juris: robustness and sensitivity analyses

Generated by `scripts/juris/render_robustness_md.py` from `data/juris/reports/robustness.json` (produced by `scripts/juris/robustness.py`, `neural_probe.py` and `ildc_check.py`). Everything uses the development years (up to 2022) **except** the two items marked *test split*, which are disclosed below.

## Reproducibility

Re-fitting the frozen shipped configuration reproduces the reported test result exactly: **75.3 % accuracy, AUC 0.795** (match with `final.json`: True). *Test split, same frozen model, descriptive analysis only; nothing was chosen from it.*

## Ablations (validation year, 20,000 training cases)

| Variant | Accuracy | AUC |
|---|---|---|
| full model | 75.4 % | 0.817 |
| no cited-section indicators | 75.6 % | 0.822 |
| no appeal type (text only) | 75.1 % | 0.814 |
| unigrams only | 74.5 % | 0.811 |
| first 15% of the pre-reasoning text only | 72.0 % | 0.769 |
| last half of the pre-reasoning text only | 73.8 % | 0.792 |

The wording carries almost all the signal: removing the explicit appeal-type input costs 0.003 AUC (the text already reveals who is appealing), and the cited-section indicators add nothing.

Accuracy is unchanged (State appeals are almost always dismissed, so the model still says so); what improves is the ranking within State appeals, which the shipped joint model could not do. It is a validated candidate, **not yet shipped**.

## Neural baseline (frozen InLegalBERT, local, validation year)

8,000 training and 3,000 validation cases, the same for every row; embeddings are the mean over the first 512 tokens of the pre-reasoning text.

| Model | AUC | Balanced acc. |
|---|---|---|
| Frozen InLegalBERT + appeal type (logistic head) | 0.760 | 68.2 % |
| TF-IDF model (Juris recipe) | 0.807 | 72.2 % |
| Late fusion (rank average) | 0.807 | 72.2 % |

A frozen encoder that sees only the first 512 tokens does not beat TF-IDF here, and fusing them adds nothing. Fine-tuning was not tried (it needs a GPU).

## The same recipe on ILDC (Supreme Court, 35k cases, outcome text removed by its authors)

| Split | Train / test | Accuracy (95 % CI) | AUC | Majority acc. |
|---|---|---|---|---|
| temporal split | 20,000 / 2,594 | 63.1 % (61.2 %-64.9 %) | 0.678 | 56.5 % |
| random 20,000 train / 2,600 test split | 20,000 / 2,600 | 70.0 % (68.2 %-71.6 %) | 0.758 | 58.5 % |

The public copy has no official split, so these are **not** the published splits; the authors' best model (a hierarchical transformer) reports 78 % on their own. They show that the plain TF-IDF recipe is a sensible baseline on ILDC (70 % on a random split) and that a temporal split costs about 7 points.

## What this does and does not show

- Juris's advantage over the trivial baselines holds in every test year and on benches it has never seen, and it can abstain usefully.
- It does not show state-of-the-art accuracy, a neural gain, or generalisation to other courts (the Supreme Court cross-check was not run).
- No human audit of the leakage cut or the labels has been done: `data/juris/release/audit_sample_200.csv` is the sheet for it.
